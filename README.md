# SQL Python Demo

**Python | SQLite | Database**

---

## About

Project demonstrating database operations with Python and SQLite. Shows how to create tables, insert data, run queries, and handle connections properly.

---

## What It Does

- Creates and manages a SQLite database
- CRUD operations (Create, Read, Update, Delete)
- Parameterized queries (SQL injection safe)
- Connection handling with context managers

---

## Tech Stack

`Python` `SQLite` `SQL`

---

## How to Run

```bash
python main.py
```
